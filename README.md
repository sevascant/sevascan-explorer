# Sevascan (SEV) — Tor-Native CPU-Only Blockchain & Desktop Wallet (`v1.0.6`)

**Sevascan (SEV)** is a decentralized, peer-to-peer proof-of-work cryptocurrency built for **100% fair CPU mining** (`SHA3-256`, zero ASICs) and **native Tor (`.onion`) privacy** with zero exposed IP addresses.

💬 **Official Community Forum & Node Directory:** [Join Sevascan Discussions](https://github.com)

## Key Specifications
* **Ticker:** `SEV`
* **Max Supply:** `80,000,000 SEV`
* **Block Reward:** `250 SEV` per block
* **Consensus:** Fair CPU Proof-of-Work (`SHA3-256`)
* **Network Layer:** Native Tor v3 (`.onion`) P2P mesh — built-in Tor daemon included
* **Address Format:** Bech32 (`sev1q...`)

## Quick Start (`v1.0.6` — 100% Automatic Setup)

1. **Download the latest release (`v1.0.6`)** from the [Releases page](https://github.com):
   * **Windows:** `Sevascan-Windows-v1.0.6.zip`
   * **Linux:** `Sevascan-Linux-v1.0.6.tar.gz`
2. **Extract and launch:**
   * **Windows:** Extract the ZIP anywhere and double-click **`Sevascan.exe`**.
   * **Linux:** Extract (`tar -xzf Sevascan-Linux-v1.0.6.tar.gz`) and launch the app binary.
3. **Automatic Sync & Self-Healing:**
   * No manual configuration or folder cleanup is required—**`v1.0.6` automatically initializes the verified chain snapshot (`#5011+`)**, starts the embedded Tor daemon, connects to the `.onion` seed nodes, and syncs to the latest block in seconds.
4. **Create Your Cold Wallet & Mine:**
   * Open **Cold Wallet (USB)** → click **Generate 12-Word Master Seed** (or restore your 12 words), save your backup, and click **Use SEV Address for Mining**.
   * Open **CPU Miner** and click **Start CPU Mining**.
